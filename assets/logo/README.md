# Logo assets (draft, pixel-art style)

Working brand: **Padala** (see `proposal.md` §12). Product line: **SporaLure Station**.
The name is not final. Run an IPOPHL trademark search before printing anything.

Generated by `make_logo.py` (Python 3 + Pillow). Edit the `HALF` sprite, the `PAL`
colours or the layouts, then run `python3 assets/logo/make_logo.py` to regenerate.

| File | Use |
|---|---|
| `padala-icon.png` / `.svg` | Square icon, transparent. App icon, sticker, stencil on the hood |
| `padala-icon-dark.png` | Same icon on night background |
| `padala-logo-stacked*.png` / `.svg` | Icon over wordmark. Pitch-deck title slide, posters |
| `padala-logo-horizontal*.png` / `.svg` | Icon beside wordmark. Document headers, banners |
| `padala-logo-sheet.png` | Preview of all variants |

Palette: onion purple `#7B2D8E` / `#B06AC2`, *Metarhizium* green `#7BC043`, cream `#FAF3E0`, night `#1E1424`.

Story: the harabas moth carries green spore dots on its wings and flies off alive. It is
the *padala* (delivery) of the cure to its own kind.
